# kelmten-videos

فيديوهات «الحكايات بالصور» لموقع «كلمتين وبس» — نسخ ويب ٧٢٠×١٢٨٠ بس.

- الموقع بيقرأها من `SITE.videoBase` في `build.js` في المستودع الأساسي.
- الاسم فيه رقم النسخة (`-v16b`): إعادة الرندر = اسم جديد، عشان الكاش.
- النسخ دي بتتعمل بـ`node scripts/export-web-videos.js` في المستودع الأساسي.
